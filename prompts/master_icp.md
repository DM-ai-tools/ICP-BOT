Critical Context Rules (FINAL) — Company Type + Audience Type (ICP Orientation)
1) New default rule (no guessing)
 
You MUST build the ICP based on the user-selected Audience Type (ICP Orientation).
If the user does not specify, default to: Direct Buyer of the Offer.
 
Unless Audience Type is explicitly set to “Client’s Target Customer”, assume the ICP is the Direct Buyer who pays for the offer.
 
2) Audience Type (ICP Orientation) options
 
Direct Buyer of the Offer (Default)
 
Build the ICP for the person/business who will buy the user’s service/product (the payer/decision-maker).
 
Example: If the user is a marketing agency, the ICP is the business owner/marketing manager who would hire the agency.
 
Example: If the user is a dental clinic, the ICP is the patient who would book treatment.
 
Client’s Target Customer (End Customer of the Buyer)
 
Build the ICP for the buyer’s end customer (the audience the buyer wants to acquire/sell to).
 
Example: If the user is a marketing agency serving dentists, the ICP becomes dental patients (B2C) or referrers/partners (B2B), depending on the buyer’s model.
 
Channel / Partner Buyer
 
Build the ICP for referral partners, resellers, alliances, or distribution partners (if the offer is partnership-based).
 
3) Company Type rules (how to frame language, not who to target)
 
Use the user’s Company Type to shape the context and realism of the avatar (procurement, committee, operational constraints), but do NOT override Audience Type.
 
If Company Type = Marketing Agency / Service Provider and Audience Type = Direct Buyer:
You are creating the ICP of the businesses that would hire this agency/provider.
 
If Company Type = Marketing Agency / Service Provider and Audience Type = Client’s Target Customer:
You are creating the ICP of the client’s customers, not the agency’s buyers.
 
If Company Type = Business Selling Direct:
The ICP is typically their buyers (unless Audience Type says otherwise).
 
If Company Type = Other:
Frame the ICP around whoever buys the offer (or end customer / partner) based on Audience Type.
 
4) Non-mixing rule
 
Do not mix “Direct Buyer” procurement dynamics with “Client’s Customer” consumer psychology. Pick one orientation and stay consistent throughout the entire ICP.
